## 方案 A：交互式推送（最简单）

直接运行：

```bash
cd D:/workbuddy/分仓组装计算
git push -u origin main
```

git 会提示：
```
Username for 'https://github.com': <你的GitHub用户名>      ← Xylia-cc
Password for 'https://Xylia-cc@github.com': <你的Token>    ← 不是账号密码！
```

⚠️ **密码位置填 Personal Access Token，不是 GitHub 登录密码**

Token 生成（约 1 分钟）：
1. 打开 https://github.com/settings/tokens/new
2. Note 填 `assembly-calculator`
3. Expiration 选 90 days
4. **勾选权限**：
   - ✅ `repo`  (读写仓库 —— 私有仓库必需)
   - ✅ `workflow` (写入 Actions 配置)
5. 拉到最底点 **Generate token**
6. 复制那串 `ghp_` 开头的字符

## 关于仓库可见性（重要）

GitHub **私有仓库**的 Pages 功能：
- 公开仓库（public）→ Pages 直接公开访问 ✅
- 私有仓库（private）→ GitHub 免费版**不支持** Pages；
  Pro 版可以，但访问需登录（同事打开会要求登录你的账号）❌ 不适合分享

**所以请把仓库设为 Public**：
仓库 → Settings → General → 勾掉 Private（即设为 Public）

或用 API 改可见性：
```bash
curl -X PATCH https://api.github.com/repos/Xylia-cc/my-dev-nest \
  -H "Authorization: Bearer <你的Token>" \
  -H "Content-Type: application/json" \
  -d '{"private":false}'
```

## 推完后确认 Pages 已开启

仓库 → Settings → Pages → Source 选 **GitHub Actions**

或直接用 API：
```bash
curl -X POST https://api.github.com/repos/Xylia-cc/my-dev-nest/pages \
  -H "Authorization: Bearer <你的Token>" \
  -H "Content-Type: application/json" \
  -d '{"source":{"branch":"main","path":"/"}}'
```

最终访问地址：
```
https://xylia-cc.github.io/my-dev-nest/
```
