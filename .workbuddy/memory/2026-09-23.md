
## 修复：替换组主件备注空白时默认取同组替代件C列配比（2026-09-23 09:20）
- 问题：用户反馈BOM备注列空白时，替换组主件配比默认=1，导致实际消耗数量不对。
- 修复：engine.js 1.4节中，当 slot.primaryRatio==null（备注无换配比）时，主件配比取 slot.children[0].cRatio（同组替代件C列配比），而非默认1。
- 四回归测试全部通过，已重新部署。

## 新增 Phase 3.5：需求满足后释放多余共享库存（2026-09-23 09:41）
- 需求：用户要求共享子件按销量占比分配后，满足需求的父件释放多余库存给未满足需求的父件。
- 实现：在 engine.js Phase 3 后增加 Phase 3.5。
  1. 回收：k_actual >= demand 的实例，回收各共享子件多余库存（allocated - demand*ratio）。
  2. 重分配：将回收库存按销量占比分配给 k_actual > 0 且 k_actual < demand 的实例（排除k_actual=0的实例，避免库存被完全无法组装的父件浪费）。
  3. 重新计算 k_actual。
- 案例：a-us-hx/1672905 原组装=262（1756080被1753589分走40），Phase3.5后1753589释放24给1672905 → 组装=286 ✅。
- 四回归测试全部通过，已重新部署。
