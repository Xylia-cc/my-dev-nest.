## ⚠️ 关键 Bug 修复：页面「打开错误」的真因（17:00~17:35）

### 现象
用户反馈「链接打开错误」。

### 排查过程（三层）
1. **旧沙箱域名 DNS 已失效**（`ENOTFOUND`）→ 沙箱被平台回收，地址名存实亡。
2. **新沙箱部署成功但返回 HTTP 403**「链接不完整」→ 分享链接需平台访问令牌（仅所有者会话有效），属平台机制，非代码问题。
3. **★ 真正让用户看到「加载错误」的代码 Bug**（浏览器自动化测试发现）：
   ```js
   // assembly_calculator/index.html 原代码
   if(SAMPLE_DATA) runCompute(SAMPLE_DATA.SAMPLE.bom, ...);
   //                ^^^^^^^^^^^^^^^ 不存在！
   ```
   `sample_data.js` 导出的是 `global.SAMPLE_DATA = SAMPLE`（顶层即 `{bom,demand,inventory}`），
   但页面按 `SAMPLE_DATA.SAMPLE.bom` 访问 → **TypeError** → 页面一打开就抛异常、什么都不显示。
   **修复**：兼容两种形态 + try/catch 兜底
   ```js
   var sd = SAMPLE_DATA.SAMPLE || SAMPLE_DATA;
   if (!sd || !sd.bom) return;
   try { runCompute(sd.bom, sd.demand, sd.inventory); }
   catch (e) { /* 写入 warnBox 提示 */ }
   ```

### ⚠️ 沙箱环境的两个坑（重要）
1. **禁止覆盖写已有文件**（`EPERM`）：`fs.writeFileSync` 覆盖已存在文件会报 `EPERM operation not permitted`。
   → 解法：**每次构建输出到全新目录**（如 `publish-<时间戳>`），或写新文件名。
2. **★ `String.replace` 的替换串不能含 `$`**：替换串里的 `$&` / `` $` `` / `$'` 会被当作特殊模式，
   `` $` `` 会插入**整个前缀字符串** → 字符串指数级膨胀 → 进程 OOM 被杀（**无任何错误输出，exit code 1**）。
   → 解法：必须用**函数形式** `html.replace(tag, function(){ return rep; })`。
   （本项目 xlsx 库中含大量 `$`，正是踩中此坑）

### 浏览器自动化验证方案（无需下载 Chromium）
`agent-browser` 的 Chromium 下载超时（网络受限），但**系统已装 Chrome**，可直接用 headless 模式：
```bash
"/c/Program Files/Google/Chrome/Application/chrome.exe" --headless=new --disable-gpu \
  --no-sandbox --virtual-time-budget=15000 --dump-dom "http://127.0.0.1:PORT/index.html"
```
- `--dump-dom` **不触发交互**，只能验证静态渲染；要验证计算逻辑，需**注入自测脚本**到页面
  （追加 `<script>` 监听 `load` 事件 → 读表格行数/表头/统计条 → 写入 `<pre id="TESTOUT">` → 再 dump DOM 提取）。
