# 2026-09-15 分仓组装量计算器

## 任务
用户要做「分仓组装量计算」：有 BOM关系表 + 各仓组装需求 + 库存，按 4 条规则算组装量。
规则：① 父件按销量降序优先；② 可替换子件按换配比合并库存；③ 共享子件互斥消耗(被先用完则后续不再得)；④ 所有子件×配比齐套才成1套，尽量组、按需求封顶。

## 交付物（D:\workbuddy\分仓组装计算\assembly_calculator\）
- engine.js：核心贪心分配算法（浏览器/Node 双兼容），含列名归一化、换配比解析、库存池、按仓+销量降序分配、消耗与瓶颈识别。
- sample_data.js：覆盖 4 条规则的示例数据。
- index.html：网页计算器（上传 Excel 三表 / 分别上传 3 个 CSV / 加载示例，计算+导出 CSV/XLSX）。
- sample_files/*.csv：上传模板。
- 已部署：https://4709d06e78884d56a539e37fd2a4cd84.app.workbuddy.host
- Node 验证：仓A P1=15,P2=0(共享C3被P1耗完),P3=3(瓶颈C5)；仓B P1=20,P4=5。全部符合手算。

## 关键约定（用户后续替换真实数据时需注意）
- 换配比方向假设：备注「换配比:2」= 2个替代子件 = 1个原配件。
- 可替换用 BOM 的「替换组」列分组（同组互为替代；主件备注空，替代件备注写换配比）。
- 共享子件按「子件+仓库」为库存池自动识别，无需额外标记。
- 缺省仓库名=「默认仓」；表头支持中英文别名。
