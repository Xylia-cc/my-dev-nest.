# 2026-11-05（续）GitHub 方案 B：仓库名修正 + 一键发布

## ★ 重要发现：仓库名带尾点
用户给的命令是 `https://github.com/<Xylia-cc>/<my-dev-nest.>.git` —— 我起初按 `my-dev-nest` 处理（去掉尖括号和尾点），**结果 404**。

实际仓库：`Xylia-cc/my-dev-nest.`（**尾点 `.` 是仓库名的一部分**）

| 项 | 值 |
|---|---|
| 完整名 | `Xylia-cc/my-dev-nest.` |
| 克隆地址 | `https://github.com/Xylia-cc/my-dev-nest..git`（**两个点**） |
| 可见性 | **公开 ✅**（不用改） |
| 默认分支 | `main` ✅ |
| 空仓库 | 是 ✅（可直接推） |

匿名探测时 `GET /repos/Xylia-cc/my-dev-nest` → 404，但 `GET /users/Xylia-cc/repos` 列表里能看到 `my-dev-nest.` ——
**教训：仓库名拿不准时，先列出用户所有公开仓库，不要只猜名字。**

修正后 `git ls-remote origin` → **HTTP 200 OK**（空仓库的 info/refs 返回 200）。

## 脚本增强（publish/github_auto_publish.js）
1. **自动确保仓库公开**：私有仓库免费版不支持 Pages，Pro 版访问需登录 → 检测到 private 就 `PATCH {"private":false}`
2. **从 API 读真实 Pages 地址**（`GET /pages` 的 `html_url`），不自己拼（仓库名含特殊字符时拼接会错）
3. Pages 开启失败时区分提示：功能未启用 / 其他错误

## 新增：Windows 一键发布
`publish/一键发布.bat` —— **双击运行**，粘贴 token（回车），自动完成：
检查仓库→构建→推送→开 Pages→打印地址。之后 token 已存，再跑直接复用。

## 最终形态（三选一）
| 方式 | 命令 |
|---|---|
| Windows 双击 | `publish\一键发布.bat` |
| 终端交互 | `bash publish/github_guide.sh` |
| 终端非交互（token 已存） | `bash publish/github_push.sh` |

唯一阻塞项。本机无 gh CLI、无 credential.helper、无已存 token；git GUI 弹窗在此环境不可用（`/dev/tty` 缺失）；GitHub Device Flow 端点 ECONNRESET。
