# 2026-10-27（续）GitHub Pages 自动发布流水线

## 需求
用户要：一个能分享给别人的链接 + 以后发版自动同步过去。

## 关键结论：沙箱链接**无法对外分享**
- 沙箱域名 `*.app.workbuddy.host` 对外访问返回 **403「链接不完整」**
- 403 页面原文：「访问该应用需要完整的分享链接，当前地址缺少访问参数」
- 枚举了 30 种常见参数名（t/token/key/sig/share/code/auth/...）**全部 403** → 令牌不是 query 参数，
  而是**由平台在服务端绑定登录会话**生成的，只有创建者自己的会话能通过
- ⇒ 沙箱链接只能自己看，**对外分发必须用外部托管**

## 新踩的坑
7. **headless 虚拟时间与 async/await 不兼容**：`--virtual-time-budget` 会快进定时器，
   但 `btnCalc` 的 `async` handler 里 `await readExcelFile()` 之后的 Promise 微任务链跟不上 →
   dump 时结果区仍是 HIDDEN，看起来像"页面坏了"。
   **排查方法**：绕过 UI 直接在页面里调 `AssemblyEngine.compute()` → 证明引擎没问题 → 是测试方法问题，非产品缺陷。
8. **Python http.server 传大文件**：1.5MB 的 xlsx 在并发场景下偶发传输不完整（curl 显示 bytes=0）；
   改用 `file://` + XHR 或内联 base64 更稳。
